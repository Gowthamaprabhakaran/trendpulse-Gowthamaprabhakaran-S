# TrendPulse – Hacker News Data Analysis Pipeline

## Project Overview

TrendPulse is a Python-based data analysis project developed to collect, clean, process, analyze, and visualize trending stories from Hacker News using its REST API.

The project transforms raw story data into structured datasets and meaningful insights through data preprocessing, exploratory data analysis (EDA), statistical analysis, and data visualization.

It focuses on understanding story popularity, category distribution, engagement patterns, and the relationship between story scores and comments.

## Project Objectives

- Collect trending stories from Hacker News using API integration.
- Clean and preprocess raw data for analysis.
- Perform exploratory data analysis to understand story patterns.
- Apply statistical analysis to identify trends and distributions.
- Generate meaningful metrics to understand story popularity and engagement.
- Create visualizations and a dashboard to present analytical results.

## Project Workflow

### 1. Data Collection

- Retrieved trending stories from the Hacker News API.
- Collected relevant story information through API requests.
- Processed JSON responses and stored the collected data for further analysis.

### 2. Data Cleaning and Preprocessing

- Removed duplicate records.
- Handled missing values.
- Corrected data types.
- Filtered unwanted records.
- Converted raw data into a structured format for analysis.

### 3. Exploratory Data Analysis (EDA)

- Explored story scores, comments, and categories.
- Identified popular stories and frequently occurring categories.
- Examined engagement patterns across different stories.

### 4. Statistical Analysis

- Calculated statistical measures to understand story score and engagement distributions.
- Analyzed popular stories and highly commented posts.
- Identified patterns and trends across the collected data.

### 5. Data Transformation

- Created additional metrics to understand story engagement and popularity.
- Organized processed information for meaningful comparisons and reporting.

### 6. Data Visualization and Dashboard

- Created charts to present story performance.
- Visualized category distribution.
- Analyzed the relationship between story scores and comments.
- Combined multiple visualizations into a TrendPulse dashboard for easier interpretation.
